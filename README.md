# Cryptography & Super Encryption Application

A comprehensive cryptography desktop/web application built to demonstrate various encryption and decryption algorithms, ranging from classical ciphers to modern algorithms and combined super-encryption.

---

## Features

This application includes 5 main processing menus designed to handle text encryption and decryption:

1. **Classical Cipher 1:** Implementation of traditional cryptography algorithms (e.g., Caesar Cipher / Vigenère Cipher).
2. **Classical Cipher 2:** Secondary classical algorithm implementation (e.g., Playfair Cipher / Hill Cipher).
3. **Modern Cipher 1:** Implementation of symmetric/asymmetric modern algorithms (e.g., AES / DES / RSA).
4. **Modern Cipher 2:** Secondary modern algorithm implementation.
5. **Super Encryption:** Advanced feature combining all 4 algorithms sequentially for enhanced security.
6. **Process Visualization:** Step-by-step display illustrating the internal execution of the encryption and decryption processes for learning purposes.
